# Politica de Seguranca

## Dados que nao devem ser versionados

- Arquivos `.env`
- Tokens, senhas e chaves privadas
- Bancos de dados reais
- Backups
- Fotos de colaboradores
- Comprovantes de entrega com dados pessoais
- CPFs, documentos pessoais e dados biometricos
- Informacoes internas de clientes ou empresas

## Relato de vulnerabilidades

Este repositorio deve ser tratado como projeto sensivel. Vulnerabilidades devem ser reportadas diretamente ao responsavel do projeto antes de qualquer divulgacao publica.

## Observacao sobre historico

Remover arquivos em uma branch nao apaga dados do historico Git. Caso dados reais tenham sido publicados, e necessario fazer limpeza de historico e rotacao de segredos em uma etapa separada.
