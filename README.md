# Gestão EPI V5.0.9

Sistema de gestão de equipamentos de proteção individual, com aplicações de
frontend e backend separadas.

## Estrutura

- `frontend/`: interface web;
- `backend/`: API e regras de negócio;
- `docs/`: documentação técnica;
- `tests/`: testes automatizados.

## Desenvolvimento

Cada aplicação possui suas próprias dependências. Instale-as e execute os
comandos de desenvolvimento dentro de `frontend/` ou `backend/`, conforme a
necessidade do ambiente.

## Segurança e privacidade

O projeto trata informações de colaboradores e pode incluir recursos de
identificação biométrica. Não envie chaves, senhas, dados pessoais, fotos ou
modelos biométricos ao repositório. Antes de uma implantação, revise controles
de acesso, retenção, auditoria e as obrigações legais aplicáveis.

Consulte [SECURITY.md](SECURITY.md) para o reporte responsável de
vulnerabilidades.
